# Project Context

## Project Name
Speed Person Tracker Home Security

## Goal
Build a local offline web application that processes uploaded CCTV videos to:
- detect persons and vehicles
- identify known vs unknown persons
- estimate vehicle speed
- generate events and alerts
- show results in dashboard, reports, and logs

## Scope Constraints
- single fixed camera
- offline batch processing
- local storage
- no live streaming
- no multi-camera support

## Current Phase
Planning and implementation setup

## Rule
Do not add features outside this scope unless explicitly decided later.
